# American Competitiveness Watch Educational Website

## Overview
A public-facing educational website that provides non-partisan civic education about American governmental systems and competitiveness. The site features a clean, document-style design with classical typography optimized for long-form reading. Includes built-in analytics system for tracking user engagement.

## Core Features

### Document-Style Layout System
- Clean, uninterrupted ivory or off-white background across all pages
- No background images, watermarks, parchment textures, emboss effects, or decorative visuals
- Classical typography system:
  - Serif body font optimized for readability and long-form content
  - Formal, declarative headings without marketing language
- Increased page margins, line height, and vertical spacing for editorial, print-like reading experience
- Responsive design for desktop and mobile with focus on text readability
- Non-partisan, educational tone maintained throughout
- Consistent document-style layout applied across all pages
- Standard header layout that scrolls naturally with page content

### Multi-Page Layout
- Main homepage with smooth scrolling navigation between 10 main sections
- Dedicated educational module subpages with consistent design
- Responsive design for desktop and mobile
- Navigation menu with links to each section and module pages
- Clean, factual presentation style
- Error boundary at app root to display user-friendly messages if components fail to load
- Document-style layout applied to main content containers on all pages
- Hero/masthead sections positioned with adequate top spacing below the header

## Analytics System

- Privacy-respecting analytics without cookies or personal data collection
- Track user engagement events:
  - Page views (one per session) for homepage and all module pages
  - Time spent on page
  - Scroll depth for each major content section

- Lightweight tracking logic that doesn't impact site performance
- Automatically updates analytics as visitors browse each section and navigate between pages

### Backend Analytics Storage
- Store aggregated analytics data as structured records

- Provide API endpoints for analytics data retrieval and updates
